# 00 · 研究总纲

## 1. 研究问题

> 一个**可微的扩散算子**（物理场）插进机器学习系统时，它到底在做什么？
> 它的作用**取决于插在哪里**还是**取决于开多大**？

这个仓库用两条完全独立的实验线、约 150 个版本回答了这个问题。

## 2. 方法族的定义

**可微物理场** = 一个参数化的谱乘子 `T[u] = F⁻¹(m(k)·F[u])`，其参数
（`s, λ, ν, a, D0, β, …`）与网络权重一起进计算图，因而可学。

实例化：

| 形态 | 数学 | 用在哪条线 |
|---|---|---|
| 热核 / 热半群 | `e^{−t|k|²}` | 概念基准 |
| Matérn / Bessel 势 | `(1 + λ|k|²_g/ν)^{−s}` | NN 线（B 线实际使用） |
| 各向异性核 | `|k|²_g = kx² + a·ky²` | NN 线（v90/v101/v102、A 线 v77） |
| 输入依赖核（Perona–Malik） | `D(x) = D0·exp(−β·I(x))` | NN 线 InfoDiff |
| 图扩散核 | `P = D⁻¹W`，`V ← PV` | **RL 线** |

基础原理全文见 [`01-foundations.md`](01-foundations.md)。

## 6. 三条硬规矩（贯穿全部版本）

1. **一次只动一根轴**。每版只有一个自变量，其余与父本**逐字相同**（用函数级 md5 校验）。
2. **零命令行开关**。配方写死在文件顶部常量里；**改配方 = 改代码**。
   裸命令 `python xxx.py` 就是获奖配置。
3. **未测 ≠ 判负**。一根轴若从未被真正读到数（崩了 / 读数丢了），
   不得据此判它无效——必须重测同一根轴，直到拿到读数。
   （NN 线的 pinn 作用面连测四次才拿到读数；前三次分别是 `NameError` / device 不匹配 / `math domain error`。）

## 7. 诚实声明

- **单 seed 为主**。RL 线全程单 seed；NN 线的 σ 是**两次独立训练之间的噪声底**
  （B 线 `σ_diff = 0.169pp`，A 线 `σ_seed = 0.71pp`），不是多 seed 标准误。
- **RL 线从未训过 α=0 的 vanilla 对照** ⇒ 不能声称"物理场优于 vanilla"。
- **大部分精度结论是 NULL**，不是正面结果。本仓库的价值主要在**机制读数**与**负面结果**。
- 跨口径数字（20K 点 vs 100K 块；max-of-N vs 末态重测；不同确定性设置）**不可直接相减**，
  表中已尽量标注。
