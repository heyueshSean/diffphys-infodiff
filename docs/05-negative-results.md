# 05 · 负面结果总汇

> **本仓库最有价值的部分。** 每一条都绑定了具体版本号与实测数字，可以直接引用编号。
> 这些结论的获取成本是约 150 次训练，其中相当一部分是 180 epoch / 800 epoch 的完整跑。

---

## A. 作用面类：哪些插法根本不可能有效

### N1 · 加性注入通道（作用面 A）整体归档 —— NN 线

- **证据**：`band_frac_mean = 0.0968`（场 90% 能量在 DC）。场输出是骨干特征的**滤波摹本**。
- **判词**：信息上必然冗余 ⇒ 加性注入通道整体归档。
- **为什么是硬结论**：场的输入就是骨干特征，场只能做线性（或保边非线性）滤波 ⇒
  **它不可能携带骨干没有的信息**。这不是调参问题，是结构问题。
- **相关**：v89（SE，97.40 / `SE_GATE_COLLAPSED`）、v98（通道粒度，97.42）、
  v101（各向异性，97.48）、v102（97.42）全部 NULL。

### N2 · 参数侧度量族（作用面 C）判死 —— NN 线

- **版本**：`cnn10_v110.py`，delivered **97.50**，判词 `SAM_SOBOLEV_DELIVERED`。
- **决定性诊断**：**`dir_ratio_mean = 0.9129`** —— Sobolev 度量只把更新方向拧了 **8.7%**
  ⇒ **事实上几乎就是裸 SAM**。
- **数学必然性**：卷积核梯度 DC 主导且 `K(0)=1` ⇒ 低通无法旋转已 DC 主导的方向。
- **连带收益**："裸 SAM（K≡1）对照跑"因此可以作废（省 ~7.5h 机时）。

### N3 · 约束通道（作用面 B）双双 `CUT_NO_CONTENT` —— NN 线

| 版本 | 切断证据 | 内容证据 | 判词 |
|---|---|---|---|
| v117 | `grad_frac_new = 0.0`（精确零）、`old = 3.6357e-5 > 0` | `band_frac_mean = 0.05526` ≪ 0.20 | `PINN_FACE_CUT_NO_CONTENT` |
| v118 | `grad_frac_smooth_new = 0.0`、`old = 1.261e-6 > 0` | `band_frac_mean = 0.038904` ≪ 0.20 | `SMOOTH_FACE_CUT_NO_CONTENT` |

⇒ 把「约束 → 场参数」的**最后一条**通路也切掉之后，**场仍然近乎 DC**。
这是"场没有自己的内容"最直接的因果证据（不是相关性）。

### N4 · 读数 / 收获族（作用面 F）判死 —— NN 线

- **v112（视图群）**：delivered 97.52，但**同权重配对 Δ = −0.18pp**（McNemar p=0.05045）。
  立项假设「各向同性核先验 ⇒ 应在平移不变群上平均」被逐视图数据**证伪**：
  中心位 97.40 / 翻转 97.38 vs 四角位均值 **96.9325**（低 **0.4575pp**）。
  ⇒ 干净角位是训练分布里几乎没见过的子集，"多视图平均"反而把噪声引进来。
- **集成（ens）**：v43–v44 起**五次负贡献** ⇒ 彻底判死。

### N5 · 网络结构改进在 RL 中全面失败 —— RL 线

BlurPool（模糊 2–3px 的球）、StochasticDepth（2 层网络 5% = 巨扰）、
频谱正则（与 RL 高频边缘需求对抗，spec loss 0.001908→0.001972 **持续上升**）、
zero-init 残差块（Adam 按梯度 RMS 归一化 ⇒ 恒等只维持 1 次前向）。
⇒ 立下铁律：**场只能改机制，不能动架构 / 核函数**。

### N6 · 物理损失是方差压缩器，不是天花板提升器 —— RL 线

v25 vs v23 的干净 A/B：TAIL CV **7.51% → 2.87%**、TAIL low **+13.4**，但 **best −12.0**。
⇒ 天花板 ~215 由容量 / PPO 动力学 / 预算决定，**不由表示平滑度决定**。

## B. 剂量类：强度几乎不决定成败

### N7 · 正则项对精度完全惰性 —— NN 线

`v118` 把 smooth 的剂量抬了 **43.9×**（`smooth_level_new = 6.546e-4` vs `old = 1.492e-5`），
精度仍然是 NULL（+0.03pp = +0.18σ）。
⇒ **"剂量大 ⇒ 有用"的直觉被实测否掉**。

### N8 · 场正则三轴全灭（5M 内）—— RL 线

| 轴 | 版本 | 结果 |
|---|---|---|
| 加剂量 | v32（调度风暴拆分） | best 213.9、final-1M 187.92 —— 无效 |
| 智能分配（按残差选样本） | v33 | b43 峰值压制 **−21.1** |
| 换形式（多尺度谱） | v34 | b43 峰值压制 **−16.5** |

**统一签名**：v33 与 v34 是**完全不同的集中轴**，却给出**同样的峰值压制签名**。
⇒ 任何"朝高能态集中剂量"的正则都会压峰；v26 的**均匀** σ=10 因保留近邻自由度而胜出。

### N9 · 永久熵下限是双刃剑 —— RL 线

`v12` CV 降到 **0.092**（全系列最稳），但峰值只有 167（对照 206）⇒ 约 **15% 天花板税**。
`v19` 的熵退火进一步证伪（W8–W10 与恒定 0.01 相差 −2 / −2 / +3）。

### N10 · 改标量权重一族整族判死 —— NN 线

`PINN_WEIGHT` / `w_phys` 这类标量只按比例缩小损失、不归零 ⇒
必须改**作用点**做拓扑切断（v47 / v57 双证）。

### N11 · `s_param` 梯度恒为 0 —— NN 线

`clamp(s_vals, 0.3, 1.3)` 在初值处饱和 ⇒ 平滑度指数 `s` **从来没被 pinn 训过**。
（这是一个"看起来在学，其实没学"的典型假绿。）

## C. 架构 / 核函数类：修得越"对"，死得越快

### N12 · 核函数的"退化"是 load-bearing 的，不是 bug —— RL 线 ★

`σ=10` 使高斯核在 `d ∈ [0,2]` 上权重为 **0.98–1.00**（完全平坦，看起来"退化"了）。
`v24` 把它"修复"成自适应 σ=0.4 + Matérn ν=1.5 + `0.7d_Q+0.3d_feat` + k 12→24
⇒ 峰值 **91.9**（v21 的 **43%**）。
⇒ **均匀平均提供的广域平滑是系统依赖的**。看着像 bug 的东西先别修，先测。

### N13 · 容量轴在冻结调度下不可行 —— RL 线

`v30`：NatureCNN 1.69M → ResNet-lite 4.10M + BlurPool + SD 0.1
⇒ best **63.2**@5.0M（−70.7%）。
根因是**相位失配**：调度按 v26 的成熟度曲线标定，大网落后一相，TAIL 干预打在**未成熟**策略上。

### N14 · 自适应闭环双向无效 —— RL 线

`v31`（成熟度触发 + 趋势门控 ×0.75/1.25）：门控的绝对剂量可忽略
（×0.75/1.25 作用在 α≈0.002 量级，增量仅 0.0004）。
⇒ **"事后反应"必然晚于"提前干预"**。

### N15 · 崩塌后救援（闭环检测）方向被证伪 —— RL 线

`v11`：末期1M **151.2** << v10 的 204.6。5 次触发中 3 次有害，
其中 9.2M 那次是**致命误报**（单块判定），把 207.3 打成 138.1。

### N16 · "四项叠加风暴"假说被证伪 —— RL 线

`v32` 把三项干预全部移走后，**4.4M 的谷仍在原位原深度**（175.2 vs 173.7）
⇒ 谷由 **ent-temper 完成单独造成**，不存在风暴。
`v28`（移动 ent ⇒ 谷跟随移动）构成**双向证明**。

### N17 · Route D：from-scratch 大参数架构做 RL 策略网络 —— RL 线 ★

`train_ppo_vit_breakout_v1.py`：ViT-Small 11M 做策略网络，reward 卡在 **1.0–1.3**@133K。
三层 bug 全修后仍无起色 ⇒ **结构性失败**：无归纳偏置 + 11M 参数 + 1024 样本/更新
⇒ 样本效率比 CNN 慢 **5–20×**。

**Route D 覆辙清单**（用户明确要求记住）：
1. from-scratch 无归纳偏置大参数架构直接做 RL 策略网络；
2. **跨架构尺度沿用超参**——1.7M CNN 的 `max_grad_norm=0.5` 裁掉 11M ViT **97–99.7%** 的梯度
   （有效 lr 缩水 40×）；
3. **含随机性组件的架构用于 on-policy RL**——StochasticDepth 破坏 importance ratio，
   clip 段零梯度 ⇒ 策略冻结；
4. 跨环境交付无版本可见性；
5. 低预算窗口（2.7%）过度判读。

### N18 · PPO 里用慢拷贝 target 网络做 GAE baseline 是根本性错误 —— RL 线

`v6`：on-policy 要求 baseline 与当前策略一致。
实现上还叠加了 `lcm(1024, 200000) = 3,200,000` ⇒ target **全程未更新**，
GAE baseline 等于随机初始化 critic。前 1.32M Avg R 只有 2–10、Max 36。

### N19 · 容量/结构在 NN 线的同证 —— NN 线

`v94` delivered **80.62**（vs v51 的 97.56，**−16.94pp ≈ 157σ**）⇒ 崩溃级断崖。

## D. 测量 / 方法论类（这些比任何一条实验结论都更容易害人）

### N20 · 不要用单点终点做版本对比

Breakout 10 集均值在相邻 20K 采样上可差 **±50%**。
`v8` 曾因 5M 单点 162.6 被误判"两头不讨好"，实际 500K 窗口均值比 v7 高 **33%**。
⇒ 项目自 8/14 起强制 **500K 窗口均值 / 100K 块均值** 口径。

### N21 · "算法级机制" ≠ "安全机制"

验证脚本必须验证「机制是否真的被调用」，而不是只验证「机制逻辑是否正确」。
**任何"该增长却不增长"的计数器都是 bug 指纹**（v5 的 440K 前三项零生效就是这么抓到的）。

### N22 · 同一份权重两个读数差的那点，可能是口径差不是噪声

`best_tta_acc` 是 179 个 epoch 的 max-of-N，必然系统性高于任何一次末态重测。
**读数时点不同 ≠ 同一观测量**。跨版比 delivered 时若 `delivered_source` 换了，就是换口径。

### N23 · "逐位一致"的判据不许打在 acc 上

必须验 `max|Δlogit| == 0`；acc 相等在 N=10000 上太粗。
旧写法 `abs(ref_acc − mcnemar(lg_ref, lg_ref))` 更是**恒真**。

### N24 · 守卫的覆盖域决定它"没坏"是什么类别

`v41` 的 `rows_ok` 只校行数没校行序；loader 固定 `shuffle=False`
⇒ 设计上不可能失败 ⇒ 不能拿它 PASS 当任何证据。

### N25 · 硬失败条件只允许"守卫不成立"

首次标定（无历史可比）时只能当标定值，不能写 PASS/FAIL。
⇒ 此时 NULL 只能读成「干预没送到」，**不许读成"机制无效"**。

### N26 · 末态吸引子律：只重塑轨迹的轴先验地 NULL

任何只改轨迹不改目标的轴（几何 / 度量 / 早期剂量），末期增益都趋于 0。
B 线逐 epoch 差分：e1-30 **+2.36pp** → e151-178 **+0.04pp**；
反向对照（v107 / v108）末期同样归零 ⇒ 末态 97.46 是**吸引子**。

### N27 · 跨跑比精度已不可判

B 线 13 版 delivered 极差 **0.280pp < 2σ = 0.338pp**
⇒ 单跑 NULL **不得升级为"轴无效"**，需 3 seed。

### N28 · 判词结论不许写死在代码里（假归档）

- A 线 `v110` 的 `dose_note` 写死「三者相差 <0.1pp ⇒ SWA 窗口轴归档」，
  而它自己的 rows 极差 **1.16pp** ⇒ 自相矛盾 ⇒ **未判即归档**。
- B 线 v118 判词写「约束通道死 ⇒ 整条线归档」，但漏了一条**从未读过数**的写场通路
  ⇒ 才有 v119（未测 ≠ 判负）。

### N29 · RL 线的方法论硬伤（必须一并披露）

1. **单 seed**——v10 与 v9 的 SMOOTH 段 200K 4.7 vs 9.1 就是不同 seed 方差；
2. **从未训过 α=0 的 vanilla 对照** ⇒ **无法声称"物理场优于 vanilla"**，
   v9 的收益可能主要来自"调度"而非"物理特征"；
3. 单游戏、无统计检验 / 置信区间。

⇒ RL 线的正确读法是：**"把场接在信用分配上有可观增益"是一个现象，不是一个已完成验证的结论。**

## E. 跨线类：同一信息层在两线命运相反

### N30 · 同一层的"信息"在不同学习目标下价值相反

| 层 | NN 线（有监督蒸馏） | RL 线（PPO 5M） |
|---|---|---|
| L2 残差通道 | **PASS+**（teacher 64.41） | **FAIL** |
| D3 谱阶梯 | **PASS+**（64.50） | **FAIL** |

⇒ **有监督锚定目标容忍正则集中，RL 峰值形成不容忍。**

### N31 · 唯一一条两线都成立的正结论

把场接在**信用分配**（RL 的 value / advantage）上有效；
接在**表征加性注入**上，两线都无效。

### N32 · 唯一一条两线都成立的负结论

**剂量几乎不决定成败**。RL 线三条正则轴（加剂量 / 智能分配 / 换形式）全灭；
NN 线 smooth 剂量抬 43.9× 仍 NULL。
