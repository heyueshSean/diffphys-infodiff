# 02 · 分支总表：两线 × 全部已测分支

> 本文是"深入到各具体分枝"的索引。每张表的最后一列是**结论**，结论为「判死 / 判负 / 归档」的分支，
> 其详细证据与可复用的教训在 [`05-negative-results.md`](05-negative-results.md)。
>
> **读数口径**：RL 线早期（v4–v13）用 20K 数据点，v14 起强制用 100K 块均值（`blk`）；
> NN 线用 `delivered`（max-of-N 交付口径）。**跨口径的数字不可直接相减**。

## 五、跨线对照：同一作用面在两线的命运

| 作用面 | RL 线 | NN 线 |
|---|---|---|
| **A（加性注入 / 架构）** | 判死（v1–v3、v30） | **判死**（v111 起整体归档；v89 / v98 / v101 全 NULL） |
| **B（约束 / 正则）** | **1 有效**（v26，但只是方差压缩器，best −12） | **判死**（v117 / v118 双双 `CUT_NO_CONTENT`） |
| **C（度量 / 优化器）** | — | **判死**（v110 `dir_ratio=0.9129`） |
| **D（信用分配）** | **★ 唯一大面积有效**（5/12） | 不适用 |
| **E（对齐目标）** | — | 待测（v119） |
| **F（读数 / 交付）** | — | **判死**（v112 视图族；ens 五次负贡献） |

**唯一一条两线都成立的正结论**：把场接在**信用分配**（RL 的 value/advantage）上有效；
接在**表征加性注入**上，两线都无效。

**唯一一条两线都成立的负结论**：**剂量几乎不决定成败**。RL 线三条正则轴（加剂量 / 智能分配 /
换形式）全灭；NN 线 smooth 剂量抬 43.9× 仍 NULL。
