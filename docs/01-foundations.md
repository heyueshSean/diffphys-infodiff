# 01 · 基础原理：可微物理场 = 一个可学的谱乘子

> 本文回答三个问题：**可微物理场在数学上是什么**、**它有哪几种插法**、**为什么插法（作用面）
> 比强度（剂量）重要得多**。后两条是本仓库全部实验的组织原则。

---

## 1. 统一视角：一切都是谱乘子

设 `u` 是某个表示张量（特征图、value 向量、logits）。本文中"物理场"指的都是下面这类算子：

```
    T[u]  =  F⁻¹ ( m(k) · F[u] )            # 频域逐点相乘
```

`F` 是 Fourier 变换（或图 Fourier 变换），`m(k)` 是**谱乘子**。所有变体——热核、Matérn 核、
各向异性核、输入依赖核、图扩散核——差别只在两处：

| 维度 | 取值 | 后果 |
|---|---|---|
| `m(k)` 的形状 | 低通 / 带通 / 重尾 / 各向异性 | 决定"什么频率被留下" |
| `m` 是否依赖 `x` | 常数 vs `m(k; u(x))` | 决定它是**线性**算子还是**非线性、保边**算子 |

**可微性**是关键：`m` 的参数（`s, λ, ν, a, D0, β, …`）与网络权重一样进计算图，于是"扩散的几何"
本身成了可学习的对象——这就是"可微物理场"这个词在本仓库里的确切含义。

---

## 2. 连续形式：从热方程到 Matérn

### 2.1 热方程与热半群

```
    ∂u/∂t = Δu            ⇒    û(k, t) = e^{−t|k|²} û(k, 0)
```

解算子 `e^{tΔ}` 就是**热半群** `S_t`。性质：

- `t` 越大 ⇒ 高频衰减越狠 ⇒ **低通**；
- 半群性质 `S_{t1} ∘ S_{t2} = S_{t1+t2}` ⇒ 多步扩散 = 一步长时扩散（C 线 `n_steps=4, dt=0.20` 就是它的离散版）；
- 物理意义：`u` 是温度场或浓度场，`t` 是时间，**信息/能量沿梯度方向从高向低扩散**。

### 2.2 Matérn / Bessel 势（B 线实际使用的核）

B 线把热核换成更灵活的一族（`cnn10_v119.py:4033`）：

```
    m(k)  =  ( 1 + λ_g · |k|²_g / ν_g )^{−s_g}
```

- `s`（平滑度指数）：控制高频衰减的**阶**——比热核重尾，能在"平滑"与"保留结构"之间连续调节；
- `λ`（长度尺度）：控制衰减发生的**频率位置**；
- `ν`（Matérn 形状参数）：控制过渡带的尖锐度；
- 数学身份：Matérn 核 = **Bessel 势** = 热半群对 `t` 的 Gamma 混合
  ⇒ 它是"不同扩散时长的加权平均"，物理上对应**多尺度扩散**。

### 2.3 各向异性

把 `|k|²` 换成度量 `g` 下的模方（`cnn10_v119.py:4032` / `4025`）：

```
    |k|²_g = kx² + a_g · ky² ,      a_g = 1 + ANISO_RANGE · tanh(aniso_param_g)   ∈ (0, 2]
```

⇒ 扩散在 x / y 方向速度不同 ⇒ **方向选择性平滑**。这是 B 线 `v90`/`v101`/`v102`、
A 线 `v77` 的"各向异性"分支的数学内容。

### 2.4 非线性 / 自适应扩散（Perona–Malik，C 线）

让扩散率依赖**局部内容**而非只依赖频率（C 线 `cnn10_info_v01.py`）：

```
    ∂u/∂t = ∇·( D(x) ∇u ) ,      D(x) = D0 · exp( −β · I(x) ) ,   I(x) = sigmoid( conv_1x1(u) )
```

`I(x)` 是**学到的信息图**：信息量高的位置扩散被抑制 ⇒ **保边扩散**（edge-stopping）。
边界条件用 Neumann（reflect pad），保证无通量流失（质量守恒）。

## 3. 变分视角：扩散 = 熵的梯度流

这是"信息扩散"这个词最深的锚点。

- **JKO / Otto calculus**：热方程 `∂u/∂t = Δu` 等价于**熵泛函** `Ent(u) = ∫ u log u`
  在 Wasserstein 空间中的**梯度流**（Jordan–Kinderlehrer–Otto, 1998）。
- 推论：所谓"信息在物理场里扩散"，严格说是 **某个熵泛函在最优传输度量下的最速下降**。
  换 `m(k)` = 换泛函 + 换度量。
- 这解释了为什么"改核"几乎总能改轨迹却很难改终点：**只要泛函仍是某个凸的熵型泛函，
  梯度流的吸引子集合不变**（本仓库 NN 线的"末态吸引子律"，见 `05-negative-results.md` N2）。

---

## 4. 信息瓶颈视角

- **Information Bottleneck**（Tishby 2000；Alemi VIB 2017）：`min I(T;X) − β·I(T;Y)`。
  CNN 的前向就是逐步的空间压缩。
- 通常的实现用**一个标量 β** 控压缩强度。C 线的做法是把 β 换成**空间自适应场**
  `D(x)`：每个位置自己决定压缩多少 ⇒ **空间自适应信息瓶颈**，且不需要显式的 IB loss
  （`I(x)` 只吃特征，形状由任务损失塑造）。

## 5. 离散图形式（RL 线）

RL 线没有空间网格，但有**状态图**。场在 rollout 批次上构造（`physics_guided_ppo_breakout_v26.py:415-447`）：

```
    dist    = cdist( normalize(q_i), normalize(q_j) )                      # q = v + (logits − mean logits)
    W       = exp( −dist² / (2σ²) )                                        # 高斯核, σ=10, k=12 近邻
    W      *= [ argmax(a_i) == argmax(a_j) ]                               # 同动作门控 = 硬边剪枝
    W      *= exp( −|v_i − v_j| / ( grad_threshold · std(v) ) )            # Perona–Malik 式梯度抑制
    P       = W / rowsum(W)                                                # 行归一化随机游走矩阵
    V_smooth= P @ V                                                        # 一步图扩散
```

`V ← P·V` 就是图上的热半群离散版（`P` 是随机游走矩阵，`P^n` 收敛到稳态 = 无限扩散）。
**注意**：这里的 `q` 空间是"动作偏好空间"，不是像素空间——扩散是在**决策相似性**上做的，
这正是 RL 线能生效而 NN 线的加性注入不能生效的分水岭（见 §7）。

## 6. 六类作用面（本仓库的分类学骨架）

同一个算子 `T`，插进学习系统的位置不同，它是完全不同的东西。这是本仓库**最重要的组织原则**。

| 编号 | 作用面 | 数学位置 | 场能改变什么 |
|---|---|---|---|
| **A** | **加性注入** | `h ← h + α·T(h)`，在中间层 | 表征内容（前向信号） |
| **B** | **约束 / 正则** | `L ← L + w·R(T(h))` | 参数轨迹（经梯度） |
| **C** | **度量 / 优化器** | `g ← T(g)`，更新方向被低通 | 优化几何 |
| **D** | **信用分配** | `V ← (1−α)V + α·T(V)`；`Adv ← Adv + α·Prop(Adv)` | 回报信号在状态间的分布 |
| **E** | **对齐目标** | 写场通路的监督目标 `target(T)` | 场本身被塑形成什么 |
| **F** | **读数 / 收获** | 推理期聚合方式 | 读出（不改变模型） |

### 6.1 为什么 B/C/F 先验地弱——"只重塑轨迹"律

若一个轴**只改轨迹不改目标**（B、C 都属此类），而目标函数与容量不变，那么它只能把你
**更快/更稳地送到同一个吸引子**，几乎不能改变吸引子的位置。
B 线的逐 epoch 差分给出了直接证据：任何只重塑轨迹的轴，末期增益都趋于 0
（e1-30 +2.36pp → e151-178 +0.04pp）。

⇒ **判据设计原则**：对 B/C 类轴，必须做**同跑内配对**（cut 掉梯度通路，看内容是否还在），
而不是比 delivered。这正是 v113–v119 一串"作用面切断实验"的由来。

### 6.2 为什么 D 是 RL 线的解

RL 的目标不是静态的：策略在变，**信用分配本身是学习信号的一部分**。
把 V 和 Adv 在"决策相似"的邻域上扩散，等于给稀疏、高方差的回报信号做了一次
**结构化降噪**——它改的是**信号**，不是"通往同一终点的路"。
这与 B/C 类有本质区别，也是 RL 线唯一跑出大增益的原因（+68% 相对提升，见 `docs/03-rl-line.md`）。

## 7. 两条线的对照：同一算子，不同命运

| | RL 线（Breakout） | NN 线（CIFAR） |
|---|---|---|
| 场定义在 | **决策相似性图**（q 空间） | **空间频率网格**（特征图） |
| 场扩散的是 | **回报 / 优势信号** | **通道特征的能量** |
| 有效作用面 | **D（信用分配）** | 无（A/B/C/F 全部判死，E 待测） |
| 为什么 | 信号本身高方差、需要结构化降噪 | 骨干已经把任务做完了；场的输出只是骨干特征的滤波摹本 |
| 决定性证据 | v26 vs v23 干净 A/B：TAIL CV 7.51%→2.87%，best −12 | `band_frac_mean = 0.0389`：切断后场 96% 能量仍在 DC |

**核心判词**：在监督学习里，一个学得的扩散场若要"有用"，它必须携带**骨干没有的信息**；
但它的输入就是骨干特征，且它只能做线性（或保边的非线性）滤波 ⇒ **它不可能携带新信息**。
而在 RL 里，场不需要携带新信息——它只需要把**已有的噪声信号**重新分配。

## 8. 术语约定

| 词 | 本文中的含义 |
|---|---|
| **物理场 / 场** | 参数化、可微的扩散算子 `T`（Matérn/热核/图核），含其参数 `s, λ, ν, a, D0, β` |
| **信息扩散** | `I(x)` 调制的扩散率（C 线）；广义上指任何让扩散率依赖内容的做法 |
| **能量扩散** | 特征能量在频率/空间上的重新分配（`band_frac` 衡量其非 DC 占比） |
| **作用面** | §6 的 A–F，场接入系统的位置 |
| **剂量** | 场的强度（`w_phys`、`α`、`field_alpha`）——**本仓库的核心发现是它几乎不决定成败** |
| **band_frac** | 场输出的能量中**非直流分量**的占比；≥0.20 视为"场有内容" |
