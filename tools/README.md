# tools · 方法论样板

本目录放的不是"辅助脚本"，而是**这套研究方法本身的可执行形式**。
如果你只想复用一样东西，复用这里的**检查链**。

## 1. `lint_train_script.py` —— preflight 通用闸门 G1–G8（静态）

抓 `py_compile` 抓不到、但会在跑到第 N 个 epoch 时才炸的 bug：

```bash
python tools/lint_train_script.py nn/cifar10/cnn10_v119.py
```

| 闸门 | 抓什么 |
|---|---|
| G1 | 调用点 kwargs 名 / 元数与函数签名不符 |
| G2 | MAYBE-UNBOUND 局部读取（只在某个 if 分支里绑定） |
| G3 | `history[...]` 的键用了但从未初始化 |
| G4 | `torch.save` 没有写前查盘守卫（磁盘满 ⇒ 崩在 C++ 侧） |
| G5 | 读了没绑定的名字（运行时 `NameError`） |
| G6 | **模块级** use-before-def（顶层顺序） |
| G7 | 自检字段的字面量不可能出现在它检查的常量里（**假绿**） |
| G8 | 模块级私有助手定义在模块级 for 循环之后（定义被跳过） |

## 2. `selfcheck/` —— 三层自证（以 v119 为样板）

| 脚本 | 层 | 干什么 | v119 结果 |
|---|---|---|---|
| `_gen_cnn10_v119.py` | **生成器（幂等）** | 由父本 + 一组补丁**确定性地产出**子版本；重复运行必须 NO-OP | NO-OP |
| `_deploy_check_cnn10_v119.py` | **部署级（静态）** | 版本同步五处、函数级 md5 零改动、新增函数计数、零 argparse、SystemExit 不增、G1–G8 | **56/56** |
| `_cnn10_v119_exec_selftest.py` | **执行级（动态）** | 真 exec 抽取模块、判词各分支真跑、变异体咬红、负向对照 | **55/55** |
| `_v119_launch_path_check.py` | **发车路径真跑** | 把训练循环**截断后真跑一遍**，证明发车路径无代码缺陷 | **ALL GREEN** |

### 两条不可协商的规则

1. **每条闸门都必须有负向对照。**
   把父本原文（或变异体）喂进去，它必须**精确地报红**。
   若父本也能通过 ⇒ 这条闸门没有区分力 ⇒ 要么改，要么标为恒等项并打印说明。

2. **生成器（幂等）的 MARKERS 必须包含本次修掉的那几行。**
   否则修完之后幂等判据会认为"已含全部 marker ⇒ NO-OP"，
   **产物没变却报 PASSED**——这是一个真实发生过、并被一整次训练暴露的假绿。

## 3. `make_manifest.py` —— 字节级 provenance

```bash
python tools/make_manifest.py     # 重新生成根目录 MANIFEST.md
```

输出每个入库文件的 **sha1 / 字节 / 行数 / 换行约定**。
发车前核对 sha1 是唯一能在一秒内区分"改了"和"没改"的手段。

## 4. 为什么要有这套东西

| 不做的代价 | 真实发生过 |
|---|---|
| 跑到第 N 个 epoch 才崩 | 一整轮 800ep 跑完才 TypeError（v109） |
| 磁盘满导致不可恢复崩溃 | 断点载荷实测 513 MB，而守卫按 96 MB 估算 ⇒ 误判"够用"（v109） |
| 终局 JSON 全丢 | `KeyError: 'c_final'`（v108）；模块级 use-before-def（v113） |
| 跑了首版而非最终片 | 整轮 180ep 白测（v116） |
| 自检恒绿但什么都没验 | 检查器读的是自己写死的字面量（G7） |
| 读数恒为 null | 探针把 `phys` 写在 `no_grad` 里 ⇒ `autograd.grad` 恒抛异常 |
